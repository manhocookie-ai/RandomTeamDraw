# RandomTeamDraw

서버 없이 실행되고 PC와 모바일에 설치할 수 있는 정적 PWA 랜덤 조 편성 앱입니다.
`web/`이 유일한 제품 버전이며 기존 C# / WPF 소스는 동작 비교용 레거시로만 유지합니다.

## 웹 버전

`web/` 폴더는 HTML/CSS/JavaScript만 사용하는 설치형 PWA입니다. 참가자 명단, 대기 순서,
배정 결과, 조 이름과 조별 가중치를 현재 브라우저의 `localStorage`에 저장합니다. 서버나 데이터베이스는
사용하지 않으며, 다른 브라우저나 기기와 데이터가 자동으로 공유되지 않습니다.

웹 기능만 확인할 때는 `web/index.html`을 직접 열 수 있습니다. 앱 설치와 오프라인 캐시는
HTTPS 또는 localhost가 필요하므로 개발용 서버에서는 다음처럼 실행합니다.

```powershell
python -m http.server 8080 --directory web
```

GitHub Pages 자동 배포 워크플로가 `.github/workflows/deploy-pages.yml`에 포함되어 있습니다.
GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로
한 번 지정한 뒤 `main` 브랜치에 push하면 웹 버전이 자동 배포됩니다.

배포 주소를 Edge 또는 Chrome에서 연 뒤 브라우저의 설치 메뉴나 화면 하단의 `앱 설치`
버튼을 사용하면 Windows 시작 메뉴와 독립 창에서 실행할 수 있습니다. 설치 버튼은 브라우저가
설치 가능 상태로 판단할 때만 표시됩니다. 첫 온라인 실행이 완료된 뒤에는 오프라인에서도 열립니다.

## 주요 기능

- 참가자 명단을 먼저 입력하고 `조 편성 시작`을 눌러 한 번에 배정
- 참가자를 추가할 때 보이지 않는 배정 대기 순서에 암호학적 난수로 삽입
- `현재 인원 + 가중치`가 가장 낮은 조에 배정하고 동률이면 암호학적 난수로 선택
- 배정 결과를 먼저 저장한 뒤 참가자 카드를 무작위 순서로 하나씩 공개
- 늦게 온 참가자는 기존 결과를 바꾸지 않고 별도로 추가 배정
- 참가자 이름 수정과 즉시 삭제
- 마지막 배정 참가자를 조 현황 상단에 크게 표시하고 목록에서도 강조
- 설정 화면에서 조 이름, 조별 배정 가중치와 애니메이션 속도 변경
- 모든 변경을 현재 브라우저에 자동 저장
- 확인 후 전체 초기화

## 조별 배정 가중치

화면 하단의 `설정` 버튼을 누르면 조 이름과 배정 가중치를 함께 변경할 수 있으며 브라우저에 자동
저장됩니다. 가중치 값 자체는 메인 화면에 표시되지 않습니다. 가중치는
`현재 인원 + 가중치`로 계산되므로 `-1`은 해당 조에 한 명을 더, `+1`은 한 명을 덜
배정하는 효과가 있습니다. 설정 범위는 -10~+10이며 세션 데이터와 함께 자동 저장됩니다.
