# TECH-001 — Technology independence

Shared governance must not mandate a programming language, framework, database or build system.

- Inspect and respect the existing project's technology and architecture.
- Configure build, lint, test, dependency and deployment commands in each project.
- Recommend a technology change only with evidence, alternatives, migration/rollback and impact analysis.
- Framework/database replacement is L3; obtain explicit prior approval.
- A sample implementation or template does not become a mandatory dependency.
