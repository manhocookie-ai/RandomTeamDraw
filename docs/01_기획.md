# 랜덤 조 편성 — 기획서

## 목표
Windows 10/11에서 실행하는 단일 화면 조 편성 앱. 이름을 한 명씩 입력하면 즉시 4개 조 중 하나에 배정한다. 빠른 현장 사용과 실수 종료 후 복원을 우선한다.

## 확정 기술
- C#, WPF, .NET 10, XAML, MVVM
- `CommunityToolkit.Mvvm` 사용 가능
- `System.Text.Json` 자동 저장, WPF 기본 애니메이션
- Windows x64 self-contained 배포

## 기능 및 규칙
1. 이름 입력 후 Enter 또는 추가 버튼으로 등록한다.
2. 4개 조 중 **현재 인원이 최소인 조**를 찾고, 동률이면 암호학적 난수 기반으로 하나를 선택한다(`RandomNumberGenerator.GetInt32`).
3. 이름 수정은 소속 조와 참가자 ID를 변경하지 않는다.
4. 삭제는 확인/Undo 없이 즉시 처리하며 다른 사람의 조는 변경하지 않는다.
5. 최근 등록자 카드는 다음 등록까지 강조한다. 수정해도 강조 유지, 해당 참가자 삭제 시 해제한다.
   조 현황 상단에는 최근 등록자의 이름과 배정된 조 이름을 크게 표시한다.
6. 전체 초기화는 확인을 받은 뒤 명단·강조를 지우고 빈 상태를 저장한다.
7. 별도 추첨 화면, 개별 재추첨, 삭제 Undo, 데이터베이스는 구현하지 않는다.

## 입력 검증
- 빈 값/공백 값 거부, 앞뒤 공백 제거, 이름 30자 제한
- 동일 이름 중복 방지(추가 및 수정 모두 적용)
- 한글 IME 조합 중 Enter 오등록 및 연타 중복 등록 방지
- 저장 실패 시 사용자에게 알리고 '저장됨'으로 표시하지 않는다.

## 데이터 및 복구
- 참가자: `Id(Guid)`, `Name`, `TeamNumber(1~4)`
- 세션: `Version`, `Participants`, `LastAssignedId`
- 저장 경로: `%LOCALAPPDATA%\RandomTeamDraw\session.json`
- 변경 성공 시마다 자동 저장; 임시 파일 기록 후 안전하게 교체하며 이전 정상 파일 백업 유지
- 시작 시 저장 데이터 복원; 손상 시 백업 복구 시도; 둘 다 손상 시 명시적으로 안내하고 원본 보존
- 자동 저장이 실제로 완료되기 전에는 저장 성공을 표시하지 않는다.
- 실행 파일 옆 `config.json`에서 1~4조 표시 이름을 변경하며, 잘못된 설정은 기본 이름으로 대체한다.

## 품질 원칙
- 화면과 도메인 로직 분리, 단일 데이터 원본
- 조별 인원은 참가자 목록에서 계산
- 불필요한 기능 및 과도한 추상화 금지
- 테스트하지 않은 기능은 검증 완료라고 보고하지 않는다.
