# 랜덤 조 편성 — 마일스톤

## M1. 핵심 배정 기능
**완료 조건**
- 참가자 추가·수정·삭제 동작
- 4개 조 최소 인원 우선 무작위 배정
- 기존 조 배정 불변(삭제/수정 시)
- 중복·빈 이름·길이 검사
- 배정 서비스 단위 테스트 통과

## M2. 단일 화면 UI
**완료 조건**
- 좌측 명단 관리 30%, 우측 4개 조 70%
- 이름 입력 후 Enter 등록 및 포커스 유지
- 참가자별 수정·삭제 조작 가능
- 최근 배정 강조는 다음 등록까지 유지
- 최근 배정자를 조 현황 상단에 크게 표시
- `config.json` 조 이름을 전체 화면에 반영
- 창 크기 변경과 긴 목록 스크롤 정상

## M3. 자동 저장과 복원
**완료 조건**
- 추가·수정·삭제·초기화 후 JSON 저장
- 재실행 시 명단·조·강조 복원
- 손상 파일/백업 복구, 저장 실패 안내
- 초기화 이후 재시작해도 과거 명단이 복원되지 않음

## M4. 마무리 및 배포
**완료 조건**
- 초기화 확인창
- 한글 IME/연타/다수 인원 등 주요 예외 점검
- Windows x64 self-contained 게시
- 실행 방법 README 및 실제 검증 결과 작성

## 진행 규칙
각 마일스톤 완료 시 구현 결과, 테스트 결과, 미해결 사항을 짧게 기록한다. 실제 환경에서 실행하지 못했다면 그 사실을 명시한다.
