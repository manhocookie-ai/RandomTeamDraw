# 랜덤 조 편성 — PWA UI 설계

## 디자인 방향

밝은 회색 배경, 흰 카드, 진한 본문색과 절제된 테두리를 유지한다. 브라우저 탭과 설치된
독립 창에서 같은 화면을 사용하며 마우스·키보드·터치에 모두 대응한다.

## 데스크톱 구성

```text
┌────────────────────────────────────────────────────────────┐
│ 랜덤 조 편성                          ● 이 브라우저에 저장됨 │
├───────────────────┬────────────────────────────────────────┤
│ 참가자 등록       │ 조 편성 현황                   총 N명  │
│ [이름 입력      ] │ [ 방금 배정 / 이름 / 조 ]              │
│ [ + 추가        ] │ ┌────────────┐ ┌────────────┐         │
│ 참가자 명단       │ │ 1조  N명   │ │ 2조  N명   │         │
│ 이름 [수정][삭제] │ └────────────┘ └────────────┘         │
│ ...               │ ┌────────────┐ ┌────────────┐         │
│                   │ │ 3조  N명   │ │ 4조  N명   │         │
│                   │ └────────────┘ └────────────┘         │
├───────────────────┴────────────────────────────────────────┤
│ 현재 브라우저에만 저장됩니다.            [설정] [전체 초기화]│
└────────────────────────────────────────────────────────────┘
```

## 모바일 구성

- 제목, 참가자 등록, 명단, 조 현황을 한 열로 쌓는다.
- 네 개 조 카드도 한 열로 배치해 가로 스크롤을 만들지 않는다.
- 설정과 초기화 버튼은 화면 너비를 나눠 터치하기 쉽게 표시한다.
- 설치 여부와 관계없이 동일한 반응형 레이아웃을 사용한다.

## 설정 화면

- 버튼 명칭은 모든 환경에서 `설정`으로 통일한다.
- 각 조의 이름 입력과 가중치 감소·현재값·증가 조작을 함께 제공한다.
- 취소는 변경 전 상태를 유지하고 저장은 검증 후 즉시 로컬 저장한다.
- 빈 조 이름이나 20자를 넘는 이름은 저장하지 않고 이유를 안내한다.

## 상호작용

1. 이름 입력 후 Enter 또는 추가 버튼으로 즉시 배정한다.
2. 성공하면 입력창을 비우고 포커스를 유지한다.
3. 최근 참가자는 다음 성공적인 등록까지 모든 관련 영역에서 강조한다.
4. 이름 수정은 기존 조를 유지하고 삭제는 확인 없이 즉시 반영한다.
5. 전체 초기화는 확인 후 참가자와 최근 배정만 지운다.
6. 조 이름 변경은 모든 기존 참가자 표시에도 즉시 반영한다.

## PWA 표현

- 설치 유도 UI는 브라우저가 설치 가능 상태를 제공할 때만 표시한다.
- 독립 창에서도 주소 표시줄이나 브라우저 뒤로가기에 의존하지 않는다.
- 첫 온라인 로드가 끝난 뒤부터 오프라인 실행을 보장한다.
- 업데이트 알림은 실제 새 Service Worker가 준비된 경우에만 제공한다.

## 접근성

- 키보드 Enter 등록, Tab 이동, 명확한 포커스 테두리를 제공한다.
- 상태와 오류 메시지는 보조 기술이 읽을 수 있는 라이브 영역을 사용한다.
- 색상만으로 조나 상태를 구분하지 않는다.
- `prefers-reduced-motion` 설정을 존중한다.
- 주요 터치 대상은 충분한 크기와 간격을 확보한다.
