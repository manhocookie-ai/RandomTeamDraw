# 랜덤 조 편성 — UI 설계서

## 디자인 방향
깔끔한 프레젠테이션형 Windows 데스크톱 UI. 밝은 회색 배경(`#F4F6FA`), 흰 카드, 진한 본문색(`#172033`), 절제된 그림자/테두리. 과도한 게임 효과 없음.

## 화면 구성
```text
┌────────────────────────────────────────────────────────────┐
│ 랜덤 조 편성                                  ● 저장됨     │
├───────────────────┬────────────────────────────────────────┤
│ 참가자 등록 (30%) │ 조 편성 현황 (70%)           총 N명     │
│ [이름 입력      ] │ ┌────────────┐ ┌────────────┐         │
│ [ + 추가        ] │ │ 1조  N명   │ │ 2조  N명   │         │
│                   │ │ 이름 카드  │ │ 이름 카드  │         │
│ 참가자 명단       │ └────────────┘ └────────────┘         │
│ 김민수 1조 [수정][삭제]│ ┌────────────┐ ┌────────────┐     │
│ 이지은 2조 [수정][삭제]│ │ 3조  N명   │ │ 4조  N명   │     │
│ ... (스크롤)      │ │ 이름 카드  │ │ 이름 카드  │         │
│                   │ └────────────┘ └────────────┘         │
├───────────────────┴────────────────────────────────────────┤
│                                           [전체 초기화]   │
└────────────────────────────────────────────────────────────┘
```

## 화면 구성요소
- 상단: 제목, 저장 상태(`저장 중` / `저장됨` / `저장 실패`)
- 왼쪽: 이름 입력 TextBox, 추가 버튼, 전체 명단, 각 행의 수정/삭제 아이콘
- 오른쪽: 1~4조 2×2 카드, 조별 인원수, 참가자 카드
- 오른쪽 상단: 최근 배정 참가자의 이름과 배정 조를 크게 표시하는 결과 배너
- 하단: 전체 초기화
- 참가자가 많으면 왼쪽 명단과 각 조 카드 내부에서 스크롤

## 색상
- 1조 파랑 `#2563EB`
- 2조 초록 `#059669`
- 3조 보라 `#9333EA`
- 4조 주황 `#D97706`
- 최근 배정 강조 배경 `#DBEAFE`, 테두리 `#60A5FA`

## 상호작용
1. 입력창에서 이름 입력 → Enter 또는 추가 클릭 → 즉시 배정.
2. 입력창을 비우고 포커스 유지. 새 참가자 카드에 짧은 페이드인(약 0.3초).
3. 새 참가자 카드를 다음 **성공적인 등록** 전까지 계속 강조. 시간이 지나도 해제하지 않음.
   같은 참가자를 오른쪽 상단 결과 배너에도 크게 표시한다.
4. 왼쪽 수정 클릭 → 이름 편집 → 저장/취소. 기존 조 유지.
5. 왼쪽 삭제 클릭 → 즉시 제거. Undo·삭제 확인창 없음.
6. 전체 초기화 클릭 → 확인창 → 승인 시 초기화 및 자동 저장.

## 화면 상태
- 초기 빈 화면: 4개 조 모두 `배정 대기`, 참가자 0명
- 저장 중: 진행 상태 표시, 성공 전 저장됨 표시 금지
- 저장 실패: 오류 안내를 지속 표시하고 조용히 무시하지 않음
- 중복/잘못된 입력: 입력 부근에 간결한 오류 메시지
- 긴 이름: 명단에서 말줄임 가능, 편집창에는 전체 이름 표시

## 접근성 및 사용성
- 키보드 Enter 등록, Tab 이동, 버튼 툴팁
- 기본 창 크기는 넉넉하게, 작은 창에서도 내용 잘림 최소화
- 색상만으로 상태를 구분하지 않고 조 번호와 인원수도 표시
- 애니메이션은 시각적 보조이며 기능 실행을 지연시키지 않는다.
